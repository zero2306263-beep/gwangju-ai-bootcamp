WHY THIS PROGRAM

교실이 아니라, 실제 클라우드 기업 현장에서 배웁니다.

Cloud Native 기술 자체뿐 아니라 현직자가 실제로 어떻게 서비스를 구성하고 운영하는지까지 연결해 이해하는 현장형 프로그램입니다.

01

NHN Cloud 본사 투어

실제 클라우드 기업의 업무환경과 기술운영 현장을 직접 확인합니다.

02

현직자 직무·기술 멘토링

Cloud Native 적용사례, 관련 직무, 현업 기술역량을 현직자에게 직접 듣습니다.

03

핵심서비스 Hands-on

Compute·Network·Storage·DB·IAM·Container를 아키텍처 관점에서 실습합니다.

04

팀 프로젝트

서비스 요구사항에 맞는 Cloud Native 아키텍처를 직접 설계하고 발표합니다.

TEAM PROJECT

최종 결과물은 ‘Cloud Native 아키텍처 설계안’입니다.

단순 실습으로 끝내지 않고, 서비스 요구사항에 맞춰 어떤 클라우드 서비스를 선택하고 어떻게 연결할지 팀별로 설계합니다.

ANALYZE

서비스 요구사항 분석

사용자·트래픽·보안·데이터 요구사항을 분석하고 필요한 클라우드 구성요소를 도출합니다.

DESIGN

아키텍처 설계

Instance, VPC, Storage, DB, IAM, Container 등을 조합해 구조를 설계합니다.

PRESENT

팀별 발표 & 피드백

설계 근거와 구조를 발표하고 현직자의 실무 관점 피드백을 받습니다.
