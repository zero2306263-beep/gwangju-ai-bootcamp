WHY THIS PROGRAM

NHN Cloud 현장교육과 자격취득을 한 과정으로 연결합니다.

Cloud Native 핵심기술을 실제 기업 현장에서 이해하고, NHN Cloud Certified - Cloud Essentials(CES) 자격시험 범위와 연결해 단계적으로 실습·문제풀이·모의평가를 수행합니다.

01

NHN Cloud 본사 투어

실제 클라우드 기업의 업무환경과 기술운영 현장을 직접 확인합니다.

02

현직자 직무·기술 멘토링

Cloud Native 적용사례, 관련 직무, 현업 기술역량을 현직자에게 직접 듣습니다.

03

핵심서비스 Hands-on

Compute·Network·Storage·DB·IAM·Container를 아키텍처 관점에서 실습합니다.

04

CES 자격시험 대비

NHN Cloud 핵심서비스를 정리하고 유형별 문제풀이와 모의평가를 통해 자격취득을 준비합니다.

CERTIFICATION

최종 목표는 ‘NHN Cloud Certified - Cloud Essentials(CES)’ 자격취득입니다.

Cloud Native 수업에서 다룬 핵심서비스를 자격시험 출제영역과 연결해 이해하고, 문제풀이와 모의평가를 통해 실제 자격시험 응시까지 준비합니다.

LEARN

핵심서비스 개념 정리

Compute, Network, Storage, Database, IAM, Security, Monitoring 등 CES 핵심영역을 체계적으로 정리합니다.

PRACTICE

유형별 문제풀이

실습에서 배운 서비스 기능과 구성 원리를 자격시험 유형에 맞춰 문제로 다시 확인합니다.

TEST

모의평가 & 시험 대비

최종 모의평가와 오답정리를 통해 취약영역을 확인하고 CES 자격시험 응시를 준비합니다.

COMPLETION

이수 및 자격연계 기준

현장교육 참여와 실습·문제풀이·모의평가를 충족하고 NHN Cloud Certified - Cloud Essentials(CES) 자격취득에 도전합니다.
