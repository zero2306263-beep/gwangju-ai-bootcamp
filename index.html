WHAT YOU DO

Cloud Native 아키텍처에서 하게 되는 활동

아래 내용은 이번 「Cloud Native 아키텍처」 몰입형 교과목의 운영내용입니다.

1

AWS 현장방문

AWS 서울 오피스를 방문해 클라우드 기업의 업무환경을 보고, 현직자 Career Talk와 질의응답을 진행할 예정입니다.

2

서비스 직접 배포

준비된 웹 서비스를 Docker로 실행하고 Amazon ECR과 EKS를 활용해 AWS 환경에 직접 배포합니다.

3

서비스 운영 실습

접속량이 늘어났다고 가정해 서비스를 확장하고, 버전을 변경하고, 장애 발생 후 자동복구되는 과정도 확인합니다.

4

CloudWatch 모니터링

서비스 상태와 로그를 확인하면서 실제 클라우드 운영에서 무엇을 점검하는지 실습합니다.

5

GitHub 포트폴리오 제작

실습 파일, 서비스 구조도, 배포 화면, 장애복구 결과를 정리해 본인이 설명할 수 있는 프로젝트 자료로 만듭니다.

6

결과 공유

마지막 날 본인이 구축한 서비스와 실습 과정을 정리하고, 프로젝트 결과를 간단하게 발표합니다.

FAQ

학생들이 가장 궁금해할 내용

비전공자인데 따라갈 수 있나요?

가능합니다. 처음부터 복잡한 코드를 만드는 방식보다 준비된 Starter Application을 활용해 Docker, 배포, 운영 과정을 단계별로 실습하는 방식으로 구성합니다.

코딩을 많이 해야 하나요?

개발 자체보다 클라우드 환경에서 서비스를 배포하고 운영하는 경험에 초점을 둡니다. 기본적인 명령어와 설정파일은 실습하면서 따라갈 수 있도록 안내합니다.

수업이 어렵지 않을까요?

Docker → ECR → EKS → Kubernetes 순서로 하나씩 연결합니다. 처음부터 EKS 환경을 직접 만드는 방식보다 준비된 실습환경을 활용해 핵심 기능을 체험하도록 운영할 예정입니다.

개인 노트북이 필요한가요?

개인 노트북 등 세부 준비물은 최종 모집공고에서 안내할 예정입니다. 계정 및 실습환경 설정도 사전에 안내합니다.

수료 후 취업에 바로 도움이 되나요?

자격증 과정은 아니지만, GitHub Repository와 배포·운영 결과를 남길 수 있어 현장실습·인턴·취업 지원 시 본인의 실습경험을 설명하는 자료로 활용할 수 있습니다.
