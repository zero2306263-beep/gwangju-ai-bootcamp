FAQ

자주 묻는 질문

비전공자도 참여할 수 있나요?

기본 실습환경과 Starter Application을 제공하는 방식으로 운영하여 비전공자도 단계별로 따라갈 수 있도록 구성합니다.

개인 노트북이 필요한가요?

세부 준비물은 최종 모집공고에서 안내합니다. 실습환경과 계정 설정은 사전 안내 예정입니다.

결과물은 무엇이 남나요?

Dockerfile, Kubernetes 배포파일, Architecture Diagram, CloudWatch 결과, GitHub Repository 등 개인별 프로젝트 결과물이 남습니다.

지금, 특별한 2박 3일을 준비하세요.

AWS 현장경험과 실무 프로젝트를 하나의 포트폴리오로 연결합니다.
