Why MLOps

AI 모델을 만드는 것에서 끝내지 않습니다.

준비된 AI 서비스를 직접 실행하고 Docker로 포장한 뒤, AWS에 배포하고 운영 상태를 확인합니다. 마지막에는 기능을 수정한 v2 서비스를 다시 배포하며 MLOps의 기본 흐름을 한 번에 경험합니다.

1

직접 실행

복잡한 모델 학습 대신 준비된 AI 프로젝트를 바로 실행하며 구조를 이해합니다.

2

AWS 배포

EC2·ECR을 활용해 AI 서비스를 실제 클라우드 환경에 올려봅니다.

3

수정·재배포

서비스를 수정하고 v2 이미지로 다시 배포하며 운영 흐름을 체험합니다.

5 Sessions

5번 수업으로 하나의 서비스를 완성합니다.

매 회차 새로운 도구만 배우는 방식이 아니라, 앞 회차의 결과물을 계속 발전시키는 연속형 실습입니다.

01 · 3H

AWS와 MLOps 첫 경험

AWS Console 접속 → EC2 확인 → 준비된 AI 서비스 실행 → 브라우저에서 결과 확인

02 · 3H

Docker로 AI 서비스 포장

프로젝트 구조 확인 → 화면·문구 수정 → Docker Image 생성 → Container 실행

03 · 3H

Amazon ECR에 이미지 저장

Repository 이해 → Image Tag 지정 → ECR Push/Pull → ai-service:v1 등록

04 · 3H

AWS에 AI 서비스 배포

ECR → EC2 배포 → 웹서비스 접속 → CloudWatch에서 CPU·Network 상태 확인

05 · 3H

MLOps 통합 미션

기능 수정 → Docker v2 생성 → ECR 등록 → EC2 재배포 → 서비스 정상 동작 확인

코딩을 잘해야 하나요?

아닙니다. 준비된 예제 프로젝트를 활용해 실행·수정·배포하는 방식으로 진행하며, 처음부터 전체 코드를 작성하지 않습니다.

AWS를 처음 써봐도 되나요?

가능합니다. AWS Console 접속부터 EC2·ECR·CloudWatch의 기본 사용법을 단계별로 실습합니다.

무엇을 만들게 되나요?

간단한 AI 웹서비스를 Docker Image로 만들고 AWS에 배포한 뒤, 기능을 수정한 v2 서비스를 다시 배포합니다.

수업에서 가장 중요한 것은 무엇인가요?

명령어 암기보다 AI 서비스가 개발 → 포장 → 저장 → 배포 → 운영 → 업데이트되는 전체 흐름을 직접 경험하는 것입니다.
